# Glossary

- Adversarial example: Input intentionally perturbed to degrade model behavior.
- DINOv2: Foundation vision model used by the SuperVLAD DINO backbone configuration.
- FGSM: Fast Gradient Sign Method adversarial attack.
- GSV-Cities: Training dataset used by the SuperVLAD training workflow.
- Recall at K: Retrieval metric measuring whether a correct match appears in the top K results.
- SuperVLAD: Visual place recognition model used as the base architecture in this repository.
- UTM: Coordinate system used in dataset filenames for positive matching.
- VPR: Visual place recognition.
