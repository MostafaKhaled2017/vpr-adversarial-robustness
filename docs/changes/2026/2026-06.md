**What changed**

- Added `rank_eval.py` for standalone query-only retrieval-native rank attack evaluation with JSON and CSV outputs.
- Added Rank-PGD-Linf, Rank-PGD-L2, and APGD-style Linf attack implementations with normalized image bounds, projection, restarts, and attack metadata.
- Added retrieval metric helpers for Recall@K, nearest-positive rank, rank displacement, and attack success rates.
- Added a rank evaluation shell wrapper and unit tests for attack projection and metric behavior.
- Moved the `faiss` import in `perceptual_adv_training/targets.py` into the target builder so importing `RetrievalAttackBatch` does not require FAISS.

**Context**

- Phase 1 of the next VPR robustness stage requires replacing weak/proxy attacks with retrieval-native attacks that directly optimize positive-vs-hard-negative rank damage.

**Impact**

- Native rank attack evaluation is available without changing existing FGSM or perceptual evaluation baselines.
- Lightweight tests can run without datasets, checkpoints, CUDA, or FAISS.
- Full benchmark results still require running the evaluator on the intended dataset and checkpoint setup.

**Validation**

- `bash -n scripts/run_rank_eval.sh` passed.
- Full `rank_eval.py` MSLS evaluation was not run because it would perform a full descriptor extraction/evaluation pass.

**Notes**

- Epsilon is interpreted in normalized image tensor space to remain comparable with `fgsm_eval.py`.
- APGD-style support is limited to Linf in this phase.
